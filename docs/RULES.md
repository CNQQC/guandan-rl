# 本地规则配置：botzone-round-lab-v2

主要对照：[Botzone GuanDan 规则及协议](https://wiki.botzone.org.cn/index.php?title=GuanDan)。本文件记录实现的选择，不宣称适配所有赛事或地方规则。

## 实现范围

- 2 副牌，108 张，4 人各 27 张；0/2 与 1/3 为固定搭档。
- 随机级牌 2 到 A；正常牌点升序 2..K,A，级牌高于 A，大小王更高。
- 红桃级牌为配子，不能配成大小王。单独出时只能作为级牌。
- 单张、对子、三张、三带二、恰好五张的顺子、恰好三连对、恰好二连三、4 到 10 张同点炸弹、五张同花顺、四王炸。
- 顺子/连对/连三中按自然顺序；A 可低可高，不允许跨越 K-A-2。普通出牌同类同张数比较；三带二只比较三张部分。
- 同点炸弹先比较张数再比较级牌顺序。四张炸弹 < 五张炸弹 < 同花顺 < 六张以上炸弹 < 四王炸。同花顺之间按自然顺序。
- 首次领牌者为 0 号；接风时，出完牌者的最后一手未被超过，交其搭档领牌；已出完玩家跳过。
- 头二游同队直接结束（双下）；否则第三家出完后结束。四人收益为相同队伍的 ±3/±2/±1。
- 单贡：末游向头游贡最大非配子牌；双贡：末游方两人各贡一张，较大贡牌交头游，同大时本实现由末游交头游。收到贡牌后按固定策略还小牌。
- 抗贡：单贡方有两个大王，或双贡方合计有两个大王；抗贡时头游领出。

## 明确的变体与限制

1. 两张纯配子单独作对子时，只枚举级牌对子；搭配其他牌型时允许合法替代普通牌。
2. 同花五张自然牌按同花顺识别。使用配子时可以申明其花色，从而区分同花顺与杂花顺。
3. 还贡优先选择 2..10 中最小的非配子牌，A 不属于“10 以下”。极端没有可还小牌时，退化为最小非配子牌；这一罕见例外需要按目标赛事另行核对。本地模型不决策还贡。
4. 同一花色、同一点数的两副牌副本互换不改变状态，因此只保留一个规范代表；**不同花色，以及用配子替代现有自然牌的选择会保留**。
5. 双下后剩余两人的内部名次没有含义，不用于跨副升级；本地训练不包含跨副等级状态与过 A 规则。
6. 原始 FableDan 的特征/枚举与本项目不兼容。本地检查点显式标记 `guandan-lab-v2`，拒绝误加载上游模型。

## 测试覆盖

`tests/test_rules.py` 包含炸弹优先级、A 的边界序列、配子合法性、花色保留、三带二比较、接风与被继续压制、进贡守恒、单双抗贡、完整对局牌数守恒，以及非法动作拒绝。

`tests/test_learning.py` 检查观察中没有其他人的手牌，花色选择确实影响特征，Torch/NumPy 推理一致，续训恢复经验回放和优化器，同策略在同牌换队评测下恰好为 50%。这些是工程证据，不是比赛认证或完整形式化证明。
